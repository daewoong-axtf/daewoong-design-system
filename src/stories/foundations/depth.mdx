## Elevation (shadow)

<div style={{ display: 'flex', gap: 'var(--dw-spacing-x6)', flexWrap: 'wrap', padding: 'var(--dw-spacing-x6)', background: 'var(--dw-bg-layer-basement)', borderRadius: 'var(--dw-radius-r4)' }}>
  {Object.keys(tokens.shadow.light).map((k) => (
    <div key={k} style={{ width: 180, height: 96, padding: 'var(--dw-spacing-x3)', background: 'var(--dw-bg-layer-floating)', borderRadius: 'var(--dw-radius-r3)', boxShadow: `var(--dw-shadow-${k})`, display: 'flex', flexDirection: 'column', justifyContent: 'flex-end' }}>

다크 모드는 알파가 훨씬 큽니다(`tokens.json` `shadow.dark`). 그림자를 한 화면에 여러 단계로 겹쳐 쓰지 않습니다.

## Overlay

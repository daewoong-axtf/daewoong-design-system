# Spacing

마진·패딩·간격은 아래 스케일 안에서만 고릅니다. 스케일 밖 수치(15px, 7px 등)는 만들지 않습니다. CSS 변수는 `--dw-spacing-<토큰>`(예: `--dw-spacing-x4`)입니다.

export const scale = Object.entries(tokens.spacing).filter(([k]) => !k.startsWith('spacing-'))
export const semantic = Object.entries(tokens.spacing).filter(([k]) => k.startsWith('spacing-'))
export const where = {
  'spacing-x-global-gutter': '화면 좌우 여백(모바일)',
  'spacing-x-between-chips': '칩·뱃지 사이',
  'spacing-y-component-default': '같은 그룹 안 컴포넌트 사이',
  'spacing-y-between-text': '제목과 설명 사이',
  'spacing-y-nav-to-title': '상단 내비게이션과 페이지 제목 사이',
  'spacing-y-screen-bottom': '스크롤 끝 하단 여백',
}

## 스케일

<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--dw-spacing-x2)' }}>
  {scale.map(([k, v]) => (
    <div key={k} style={{ display: 'flex', alignItems: 'center', gap: 'var(--dw-spacing-x3)' }}>
      <code style={{ width: 64, flexShrink: 0 }}>{k}</code>
      <div style={{ width: `var(--dw-spacing-${k})`, height: 16, background: 'var(--dw-bg-brand-solid)', borderRadius: 'var(--dw-radius-r0_5)' }} />
      <span style={{ fontSize: 'var(--dw-font-t3-size)', color: 'var(--dw-fg-neutral-subtle)' }}>{v}</span>
    </div>
  ))}
</div>

## 의미 간격

자리가 정해진 간격은 이름으로 부릅니다.

<table>
  <thead><tr><th>토큰</th><th>값</th><th>쓰는 자리</th></tr></thead>
  <tbody>
    {semantic.map(([k, v]) => (
      <tr key={k}><td><code>{k}</code></td><td>{v.replace(/[{}]/g, '').replace('spacing.', '')} ({resolve(v)})</td><td>{where[k]}</td></tr>
    ))}
  </tbody>
</table>

## 화면 좌우 여백

| 이름 | 최소 너비 | 화면 좌우 여백 |
| --- | --- | --- |
| (기본) | 0 | 16px (`spacing-x-global-gutter`) |
| `xs` · `sm` | 480 · 640px | 16px |
| `md` | 768px | 24px |
| `lg` · `xl` · `2xl` · `3xl` · `4xl` | 1024 · 1280 · 1536 · 1920 · 2560px | 32px |

콘텐츠 최대 너비는 정보형 페이지 1040px, 넓은 목록·대시보드 1280px입니다.

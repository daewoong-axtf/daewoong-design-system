# Shape

모서리 둥글기(radius)와 테두리 두께를 다룹니다. CSS 변수는 `--dw-radius-<토큰>`입니다.

## Radius

export const where = {

이름 없는 단계(`r0_5` · `r1_5` · `r2_5` · `r3_5` · `r6`)는 컴포넌트 명세가 지정할 때만 씁니다. 중첩된 면은 **바깥 radius = 안쪽 radius + 사이 간격**입니다.

## 테두리

- 테두리는 1px `solid`가 기본입니다. 구분선은 `stroke-neutral-muted`.
- 입력 필드 포커스는 테두리를 2px `stroke-neutral-contrast`로 바꿉니다.
- 구분선을 목록 마지막 항목 뒤나 메뉴 항목 사이에 넣지 않습니다.

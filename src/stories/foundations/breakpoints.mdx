# Breakpoints

화면 너비에 따라 배치를 바꾸는 기준점입니다. 휴대폰 화면을 기본으로 만들고, 너비가 기준을 넘을 때마다 넓은 배치로 바꿉니다. 아래 값 밖의 기준은 만들지 않습니다.

| 이름 | 최소 너비 | 기준 기기 | 좌우 여백 |
| --- | --- | --- | --- |
| (기본) | 0 | 휴대폰 | 16px |
| `sm` | 640px | 큰 휴대폰 | 16px |
| `md` | 768px | 태블릿 | 24px |
| `lg` | 1024px | 작은 데스크톱 | 32px |
| `xl` | 1280px | 데스크톱 | 32px |
| `2xl` | 1536px | 넓은 데스크톱 | 32px |

Tailwind 기본값과 같아서 `md:`처럼 그대로 씁니다. `md` 미만을 모바일로 봅니다.

CSS 미디어 쿼리에는 변수를 쓸 수 없어 숫자를 그대로 적습니다. 아래를 뜻할 때는 `max-width: 767px`처럼 값에서 1을 뺍니다. JS에서는 `--dw-breakpoint-*`로 읽습니다.
